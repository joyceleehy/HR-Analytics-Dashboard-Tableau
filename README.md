# HR Analytics Dashboard

## Project Overview

This project is an HR Analytics Dashboard created using Tableau Public. It analyzes employee attrition, workforce demographics, job satisfaction, and department-level trends.

View the interactive dashboard on Tableau Public:

[Open Tableau Public Dashboard](https://public.tableau.com/app/profile/joyce.lee.how.yee/viz/HRAnalyticsDashboard_17637073405650/HRAnalyticDashboard)


## Key Metrics

- Employee Count: 1,470
- Attrition Count: 237
- Attrition Rate: 16%
- Active Employees: 1,233
- Average Age: 37

## Dashboard Features

- Employee count and attrition KPI summary
- Department-wise attrition analysis
- Attrition by gender
- Employee distribution by age group
- Job satisfaction rating by job role
- Education field-wise attrition
- Attrition rate by gender across different age groups

## Key Insights

- The overall attrition rate is 16%.
- The R&D department has the highest attrition count.
- Employees aged 25 to 34 have a high attrition concentration.
- Life Sciences and Medical education fields show the highest attrition counts.
- Sales Executive and Research Scientist roles show notable attrition patterns.
